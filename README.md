# Flutter Namer Modernized

A word-pair generator updated for Flutter 3.47 and Material 3.

## Modernization changes

- Replaced the deprecated `ColorScheme.surfaceVariant` color.
- Migrated the compact layout from `BottomNavigationBar` to `NavigationBar`.
- Updated all public widget constructors to accept keys using super parameters.

The relevant source comments explain what changed and why.

## Run

```sh
flutter pub get
flutter run
```
